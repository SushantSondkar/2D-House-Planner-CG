2D House Floor Plan Designer

An OOP + Computer Graphics project built with C++ and SFML

Download v1.0 (Windows) View Source Code

Features

  • Draw walls on a 1 grid = 1 m scale with snapping
  • Resize and orient walls, with live dimensions
  • Add rooms, doors, windows and staircases
  • Automatic room and total area calculation
  • Export your final plan

How to run

Download the zip, extract it, and run the .exe inside. No installation needed.
